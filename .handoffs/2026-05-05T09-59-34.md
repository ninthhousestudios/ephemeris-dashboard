## Pick up next

**Recommended order: `swe-dashboard/1` first, then `swe-dashboard/2`.**

CalcSession is smaller and safer. It also removes the `if (trigger == 0)`
guards from result providers, which makes the EphemerisRunner diff
cleaner to review.

The two tasks have a `relates_to` edge but no `depends_on` — either can
ship first if there's reason to.

### `swe-dashboard/1` — CalcSession

Read `doc/calc-session-design.md`. Migration steps are listed in the
task's acceptance_criteria. Key idea: one global `CalcSessionNotifier`
holding `version: int`, `lastRunAt`, `tabsRun: Set<String>`. Calculate
is global; placeholder gating is per-tab via `tabsRun`.

Validation: all 54 golden tests pass. `flutter test` green.

### `swe-dashboard/2` — EphemerisRunner

Read `doc/ephemeris-runner-design.md`. Migration is 7 steps; pilot with
Planets, then convert other tabs one per commit. Kills
`EffectiveContext.calculate()` and `ephePathApplyProvider` at the end.

Validation: all 54 golden tests pass. No observable behavior change.

## Out of scope but on the radar

These came out of the Codex architecture review (`doc/reviews/codex-review.md`)
but are not in the current waves:

- **Export header bug** — `lib/core/export_service.dart` `toTsv` and
  `toCsv` use `rows.first.fields` as the column header. Breaks for
  tabs with heterogeneous rows (Houses, Dates, Nodes/Apsides). Small
  fix (~20 lines: union labels across rows, or per-row sectioned
  export). No abstraction needed despite what the review suggested.
- **Context hydration microtask** —
  `ContextBarNotifier._loadPersisted()` returns `{}` and `AppShell`
  patches state in a microtask after first frame. ~30 minute cleanup;
  defer until it actively bites.
- **v2 "tracing-driven code generation"** in `doc/swe-dashboard-v2.md`
  remains an open plan. EphemerisRunner is the prerequisite seam — once
  it lands, v2 has somewhere to plug.
